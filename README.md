# World Population EDA


## Problem
- Population data for countries across several decades is hard to understand as a raw table. This project explores it to find which countries and continents are largest, and how they have changed over time.

## What I did
 - Checked the data for missing values and unique values per column
 - Ranked the most populated countries
 - Compared continents using averages and grouping
 - Measured how population columns relate using a correlation heatmap
 - Plotted average population by continent from 1970 to 2022
 - Used a box plot to spot outliers

## Key findings
- From 1990, the average country population in Asia grew much faster than in any other continent
- India and China are far ahead of every other country in 2022, each with over 1.4 billion people.
- Asia has the highest average country population, and from 1990 it grew faster than any other continent 
- The biggest country in each continent is: Nigeria (Africa), China (Asia), Russia (Europe), United States (North America), Brazil (South America), Australia (Oceania).
- Population columns from different years are almost perfectly correlated, so countries that were large in 1970 are still large in 2022.
- The box plot shows a few countries far above the rest, so population is very unevenly spread.
